# Python - Classes & Object Model

This project introduces the fundamentals of classes and objects in Python.

## Description

The project explores how Python uses objects internally and how to create custom classes.

The exercises cover:

* Exploring existing Python objects
* Understanding classes and instances
* Creating objects from classes
* Defining and initializing instance attributes
* Implementing instance methods
* Managing object state
* Applying basic encapsulation principles
* Validating input when constructing objects
* Controlling access to internal attributes
* Implementing string representations with special methods

## Learning Objectives

By completing this project, you should be able to:

* Explain the difference between a class and an instance
* Create classes that model simple entities
* Define and initialize instance attributes using `__init__`
* Implement instance methods that operate on object state
* Apply basic encapsulation principles
* Validate input when constructing objects
* Control access to internal attributes
* Implement string representations using special methods
* Design simple classes that model real-world concepts
