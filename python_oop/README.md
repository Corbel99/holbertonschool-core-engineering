# Python - Object-Oriented Programming

This repository contains exercises and projects focused on Object-Oriented Programming (OOP) in Python.

## Topics

The projects cover fundamental concepts of Python's object model, including:

* Classes
* Objects and instances
* Instance attributes
* Methods
* Object state
* Encapsulation
* Input validation
* Special methods
* String representations

## Goal

The goal is to develop a solid understanding of Python's object model and learn how to design simple classes that model real-world concepts.

These concepts provide the foundation for more advanced OOP topics such as:

* Inheritance
* Polymorphism
* Abstract classes
