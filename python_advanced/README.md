# Python - Advanced

## Description

This directory contains advanced Python projects completed as part of the Holberton School curriculum.

The projects focus on developing a deeper understanding of Python and its features through practical exercises and progressively more advanced concepts.

## Projects

### File Handling

The `file_handling` project introduces Python input/output mechanisms and file manipulation.

Topics include:

* Opening files
* Reading files
* Writing text to files
* Appending data to files
* Reading files line by line
* Moving the cursor within a file
* Properly closing files
* Using the `with` statement
* Working with text files and UTF-8 encoding

## Requirements

Projects in this directory are developed using:

* Python 3
* Ubuntu 20.04 LTS
* pycodestyle 2.7.*

Each project follows the specific requirements and constraints provided by Holberton School.
