# Python - Core Data Structures

## Description

This project introduces the core built-in data structures available in Python and the reasoning needed to use them correctly.

The project focuses on:

* **Lists** — ordered, mutable sequences
* **Tuples** — ordered, immutable groupings
* **Sets** — collections of unique elements and set operations
* **Dictionaries** — key-value mappings

The tasks consist of small functions designed to manipulate these data structures predictably and safely.

## Learning Objectives

By completing this project, I will learn how to:

* Iterate over lists and matrices and produce exactly formatted output.
* Access and modify list elements safely.
* Create new collections without modifying the original input when required.
* Use tuples to return multiple values.
* Use sets to calculate intersections and symmetric differences.
* Use dictionaries to add, update, and query key-value data.
* Handle edge cases such as empty inputs, missing keys, and repeated values.
