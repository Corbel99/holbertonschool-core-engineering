# Python - Exception Handling

## Description
Ce projet fait partie du cursus de programmation Python. Il traite de la gestion des exceptions (`try / except`), de la manipulation des listes sans utiliser la fonction `len()`, et du respect des normes de style PEP 8 (`pycodestyle`).

## Fichiers

| Fichier | Description |
| --- | --- |
| `0-safe_print_list.py` / `safe_print_list.py` | Fonction qui imprime $x$ éléments d'une liste et retourne le nombre réel d'éléments imprimés. |

## Prérequis
* Python 3.8+
* `pycodestyle` (version 2.8+)
