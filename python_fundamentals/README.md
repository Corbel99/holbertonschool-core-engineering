# Python - Environment & First Programs

This directory contains the exercises for the
"Python - Environment & First Programs" project.

## Learning Objectives

By the end of this project, you should be able to:

- Distinguish between expressions and statements in the interpreter.
- Predict when output will appear automatically in interactive mode.
- Create a portable, executable Python script.
- Install and use a development tool via `pip`.
- Explain the difference between global installations and isolated environments.
- Demonstrate dependency isolation using `venv`.

## Requirements

- Ubuntu 20.04 LTS
- Python 3.8.x
- pycodestyle 2.7.x

## General Requirements

- Every Python file must start exactly with:
  `#!/usr/bin/env python3`
- Every Python file must be executable.
- Every Python file must end with a newline.
- Every Python file must be PEP 8 compliant.
- Code must pass pycodestyle 2.7.x.
- Output must match the expected formatting exactly.
- No external libraries are allowed unless explicitly requested.

## Allowed Functions and Libraries

No specific functions or external libraries are explicitly listed as
allowed in the project requirements.

Only the Python standard library and functionality required by each
task should be used, unless a task explicitly requests otherwise.

- `structured_output.py` - deterministic Python script output.
